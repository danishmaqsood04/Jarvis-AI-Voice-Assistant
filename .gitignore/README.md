# Jarvis AI Voice Assistant

A Python-based AI Voice Assistant for Windows.

## Features

- Voice Commands
- Google Search
- YouTube Search
- Open Chrome
- Open VS Code
- Open Notepad
- Calculator
- Screenshot
- Battery Status
- Volume Control
- Brightness Control
- Open Downloads
- Open Documents
- Open Desktop

## Technologies

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- MSS
- PyCAW
- Screen Brightness Control

## Run

```bash
pip install -r requirements.txt
python main.py
```
